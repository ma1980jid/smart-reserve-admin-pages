# نظام الغياب الإلكتروني المدرسي

نسخة تجريبية مرفوعة أونلاين داخل مجلد `attendance`.

## الروابط

- الرئيسية: `attendance/`
- صفحة المعلم: `attendance/teacher.html`
- صفحة الإدارة: `attendance/admin.html`
- متابعة التسجيل: `attendance/followup.html`
- لوحة الغياب: `attendance/dashboard.html`

## ملاحظات

- صفحة المعلم مخصصة للهاتف.
- صفحات الإدارة والمتابعة ولوحة الغياب مخصصة للحاسوب.
- الحفظ في هذه النسخة يتم داخل المتصفح فقط باستخدام LocalStorage.
- للاستخدام الحقيقي بين أجهزة مختلفة يجب ربط النظام لاحقًا بـ Microsoft Lists / SharePoint أو قاعدة بيانات سحابية.
